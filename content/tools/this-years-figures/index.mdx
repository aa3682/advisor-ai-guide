# This year's figures

This page is the one place on the site that prints figures set by law, regulation, or an agency: limits, rates, thresholds, and deadlines. It holds no figures set by an AI platform, such as pricing, data-retention windows, or usage limits; those change on the vendor's schedule, so check them live with the [Vetting a Vendor checklist](/tools/vetting-a-vendor). The Firm Function pages name each concept in plain language and link here, so a figure changes in one place.

Every value carries the year it applies to and a link to its primary source. A figure fixed by statute shows "Set by statute" in the Year column. A figure that differs from state to state shows "Varies by state" and points you to where to look. Each figure appears once, under the Firm Function it fits best; if you do not see it under the area you came from, use your browser's find. The page is reviewed once a year.
