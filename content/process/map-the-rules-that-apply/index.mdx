# Map the Rules That Apply

This is the second step in The Adoption Path. There is no separate AI rulebook for advisers. Every use on the inventory from [Decide What AI Is For](/process/decide-what-ai-is-for) already falls under rules the firm follows today; this step maps each use to the duties it touches, so the policy in [Write the AI Policy](/process/write-the-ai-policy) is written against real obligations instead of general caution. The [duty map](/glossary#duty-map) itself is short — a small firm's version fits on one page — and it is usually the first document an examiner asks to see.

## Why it matters

Skipping this step tends to produce one of two mistakes. The first is treating AI as unregulated territory, because no rule mentions it by name — true, and beside the point, since the duties that already apply to how advice is produced, documented, and disclosed do not stop applying just because a new tool is involved. The second is waiting for a dedicated "AI rule" before acting at all, which can stall a firm indefinitely, since no such rule exists in the way the question assumes. Mapping the rules that already apply replaces both mistakes with something concrete: a short document that says, for each use, exactly which obligations it touches.

## What actually happens

### Start from the rules you already follow

Before looking at any specific use, name the duties that apply to the practice generally. Keep the description in plain language and put the citation in a table, so the page stays readable:

| Duty | What it means here | Where it applies |
|---|---|---|
| Duty of care and loyalty | You still owe every client suited, well-researched advice and disclosed or avoided conflicts, however a recommendation was produced | [Advisers Act §206](https://uscode.house.gov/view.xhtml?req=granuleid%3AUSC-prelim-title15-section80b-6&num=0&edition=prelim) |
| Written compliance policies and procedures | Your policies have to actually describe how AI is used and supervised, not just note that a [compliance program](/glossary#compliance-program) exists | [Advisers Act Rule 206(4)-7](https://www.ecfr.gov/current/title-17/chapter-II/part-275/section-275.206(4)-7) |
| [Books and records](/glossary#books-and-records) | What a use produces, and how it was reviewed, is kept the same way any other advisory record is | [Advisers Act Rule 204-2](https://www.ecfr.gov/current/title-17/chapter-II/part-275/section-275.204-2) |
| Marketing and [advertising](/glossary#advertisement) | Anything AI helps draft that a client or prospect could see falls under the same [substantiation](/glossary#substantiation) rules as advertising written by hand | [Advisers Act Rule 206(4)-1](https://www.ecfr.gov/current/title-17/chapter-II/part-275/section-275.206(4)-1) |
| Safeguarding client information | Client data entered into a tool is still client data, covered by the same privacy and security obligations as anywhere else it is stored | [Regulation S-P](https://www.ecfr.gov/current/title-17/chapter-II/part-248/subpart-A) |
| Disclosure documents | If AI use is significant enough to shape how advice is produced, it may need to be described in the firm's own [brochure](/glossary#brochure) | [Advisers Act Rule 204-3](https://www.ecfr.gov/current/title-17/chapter-II/part-275/section-275.204-3) |

Most of the table cites rules written for [SEC-registered advisers](/glossary#sec-registered-adviser). For those duties a [state-registered adviser](/glossary#state-registered-adviser) is under the state's own requirements, which vary — so the "Where it applies" column is where you substitute your own state's rule. The first row is different: the statute cited there applies by its own terms to any investment adviser, whether or not registered with the Commission, so a state-registered firm is under it directly.

This table is the starting inventory of duties, not the finished map — the next piece connects each use to the rows that actually apply to it.

### Map each inventory item to the duties it touches

Take the [use-case list](/glossary#use-case-list) from step one and run each item against the table. A round hypothetical example: drafting quarterly client letters with a chat assistant touches at least three duties — books and records (the draft and the final version are both records), marketing and advertising if the letter goes to prospects as well as clients, and the compliance-policy duty, since the firm's procedures need to say who reviews the letter before it goes out. A back-office use, like summarizing an internal meeting, might touch only books and records. Write the duties next to each use on the inventory; a use that touches no duty on the table is unusual enough to be worth a second look.

### Check your own regulator's statements on AI

Duties that predate AI are only half the map. State-registered firms should check their state securities regulator's own published guidance and bulletins, and the model rules and guidance the state regulators' association, NASAA, publishes for its members to adopt. SEC-registered firms should check the SEC's published [examination](/glossary#examination) priorities, [risk alerts](/glossary#risk-alert), and staff statements, which name current areas of focus even when they do not create new rules. None of this needs summarizing from memory — go to the regulator's own site, find what is currently published, and note the date you checked.

### Check whether dual registration changes the map

An adviser who is also a [registered representative](/glossary#registered-representative) of a [broker-dealer](/glossary#broker-dealer) has a second rulebook and a second supervisor. A use that is fine under the adviser's own duties can still need sign-off from the broker-dealer's compliance department, and the two sets of procedures do not automatically match. If this applies to you, the map has two columns, not one.

### Write the map down and date it

The output of this step is a short, dated document: each use from step one, the duties it touches, and where you checked for AI-specific guidance. It becomes an appendix to the policy in [Write the AI Policy](/process/write-the-ai-policy), and it gets re-checked in [Review and Keep Records](/process/review-and-keep-records) — rules and guidance change, and a map that is never revisited goes stale the same way an unused policy does.

## Questions to ask yourself

- For each use on your inventory, which duties in the table does it touch — and did you write that down, or just think it through once?
- Have you checked your own regulator's currently published guidance, or are you assuming it says what a similar firm's guidance says?
- If you are a [dual registrant](/glossary#dual-registrant), does your broker-dealer's compliance department already have a view on this?
- Is there a use on the inventory that seems to touch no duty at all — and if so, why?
- When did you last check this map, and is that date written down anywhere?

## Common mistakes

- Waiting for a dedicated "AI rule" before acting, when the duties that already apply do not pause for a new category of tool.
- Assuming a [general-purpose tool](/glossary#general-purpose-tool)'s own terms of service settle what the firm's own obligations are — a vendor's policy and a fiduciary duty are not the same thing.
- Forgetting that an assistant's use is still supervised use, and mapping the rules only against what advisers do.
- Treating a marketing draft as internal because a tool produced the first version, rather than because a person has not yet reviewed it.
- Mapping the rules once, at the start, and never re-checking as the inventory or the guidance changes.

## Which Firm Functions apply

- [Compliance and Supervision](/domains/compliance-and-supervision): The map is the document this Firm Function is built around — it is what supervision actually checks against.
- [Records and Documentation](/domains/records-and-documentation): Several of the duties in the table are recordkeeping duties, and the map itself is a record.
- [Data Privacy and Security](/domains/data-privacy-and-security): Safeguarding client information is one of the duties every use has to be checked against.
- [Client Communication and Marketing](/domains/client-communication-and-marketing): Any use that touches something a client or prospect could see runs into the marketing and advertising duty in the table.

<Callout type="info">
At a larger firm, this map already exists and belongs to compliance, not to an individual adviser. The job at a larger firm is not to build a new map from scratch; it is to ask which specific duties in the existing map a proposed use touches, and get that answer in writing before using anything the firm has not already cleared.
</Callout>
